# PlayTimer

PC방처럼 하루 사용 시간을 재다가, 시간이 끝나면 **강제로 끄지 않고 끄라고 계속 조르는** 윈도우 트레이 앱입니다.

## 설치

설치할 것은 없습니다. 윈도우에 기본으로 들어 있는 .NET Framework 컴파일러로 빌드합니다.

1. 이 폴더를 원하는 위치(예: `C:\Tools\PlayTimer`)에 둡니다.
2. `install.bat`을 실행합니다. 빌드한 뒤 로그인할 때마다 자동으로 실행되도록 등록하고, 바로 시작합니다.
3. 트레이 아이콘을 더블클릭해서 **시간 설정** 창을 열고 시간표를 정합니다.

## 시간 설정

캘린더 앱의 주간 보기처럼 생긴 창에서 두 가지를 정합니다.

- **요일별 하루 총량**: 위쪽 칸에 0.5시간 단위로 입력합니다.
- **써도 되는 시간대**: 아래 격자를 드래그해서 30분 단위로 칠합니다. 칠한 칸에서 드래그를 시작하면 지워집니다. 여러 요일에 걸쳐 드래그하면 같은 시간대가 한꺼번에 칠해집니다.

둘 중 **먼저 끝나는 쪽**에 맞춰 경고하고 조릅니다. 예를 들어 평일 총량 2시간, 시간대 18:00~22:00이면, 2시간을 다 썼거나 22시가 넘으면 알림이 시작됩니다. 칠하지 않은 시간에 PC를 켜도 바로 조르기 시작합니다.

- 하루는 새벽 4시에 시작하므로(`ResetHour`), 금요일 칸 아래쪽의 00:00~04:00은 토요일 새벽입니다.
- "월 → 평일 복사", "토 → 일 복사", "모두 칠하기", "모두 지우기" 버튼이 있습니다.
- 시간대 칸 아래 숫자가 주황색이면 칠한 시간대가 총량보다 짧다는 뜻입니다.
- 시간표는 `%LOCALAPPDATA%\PlayTimer\schedule.txt`에 저장되고, 저장하면 바로 적용됩니다.

조르는 강도(단계 전환 시점, 다시 뜨는 간격, 연장 횟수)는 `config.ini`에서 고칩니다.

빌드만 하려면 `build.bat`, 자동 실행을 해제하려면 `uninstall.bat`을 실행하세요.

## 동작

- 트레이 아이콘에 남은 시간(분)이 표시됩니다. 더블클릭하면 시간 설정 창이 열립니다. 파랑 → 주황(10분 이하) → 빨강(초과).
- 남은 시간이 10분, 5분, 1분일 때 오른쪽 아래에 경고가 뜹니다.
- 시간이 끝나면 단계적으로 강해집니다.
  1. **0~10분 초과**: 작은 팝업, 닫으면 2분 뒤 다시 뜸
  2. **10~20분 초과**: 큰 빨간 팝업, 10초 동안 못 닫음, 1분마다 다시 뜸
  3. **20분 이상 초과**: 모든 모니터를 덮는 전체화면, 20초 동안 못 닫음, 1분마다 다시 뜸
- 팝업에서 바로 **PC 끄기**(1분 뒤 종료)나 **연장**(기본 하루 1회, 30분)을 누를 수 있습니다. 시간대가 끝나서 조르는 중이면 시간대도 30분 늘어납니다.
- 화면 잠금, 절전 중에는 시간이 흐르지 않습니다.
- 사용 시간은 `%LOCALAPPDATA%\PlayTimer\state.txt`에 저장되어 재부팅해도 유지됩니다. 하루는 새벽 4시에 바뀝니다(`ResetHour`).

## 알아둘 점

- 본인 절제용이라 트레이 메뉴의 "타이머 종료"나 작업 관리자로 끌 수 있습니다. 종료할 때 확인 창이 한 번 뜹니다.
- 전체화면 독점 모드로 실행되는 게임 위에는 팝업이 보이지 않을 수 있습니다. 게임을 "테두리 없는 창 모드"로 설정하면 잘 보입니다.
